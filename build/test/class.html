Phone1st Classes

Experimenting with classes.

Phone1st uses the color palette from Tailwind css.

A mixin is used to generate all the classes. In the class folder the _class-helpers.scss imports all the partials as maps and with a mixin adds breakpoints, colors and size where needed.

To add a class is simple you just add it to the map partial. In development the output file style.css in the build folder weighs about 82kb. In development the mixin generates a lot of classes. In production the unused css styles should be purged and the file should come down to about 28kb.

You can take the class utilities as far as you like or you can easily remove them

How it works

See - css/root/_base-color.scss, css/root/_variables.scss, css/root/mixins, css/class/...all-files

The _class-helpers.scss imports all the partials and runs them through a mixin to generate classes adding breakpoints, color and spacing where necessary

The color palette is from Tailwind. To use the colors is simple, being color name and shade eg blue-500. Precede it with what you want to color eg text-, bg- or border-. Add a breakpoint or hover.

Spacing

Spacing works with the $s-0 to $s-15 in the _variables.scss. See the css/class/_spacing.scss file

The margin, padding, width, height and gap take the spacing values
